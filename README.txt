AIMEE NOELLE DELFINO DIGITAL CARD
=================================

Edit the CARD = { ... } block near the bottom of index.html. Empty fields are hidden on the page and in the saved contact.
Photo: put photo.jpg in this folder and set photo: "photo.jpg".

Test locally:  python -m http.server 5190  (then open http://localhost:5190)

NFC: in the NFC Tools app choose Write > Add a record > URL/URI, paste the live link, then hold the card to the back of the phone.
The card never needs rewriting when the page changes.
